# Tips

This section will be updated regularly whenever I find a new Linux tip.

- To automatically complete a command, file name, or directory name, press `Tab`.
- If there are multiple possible completions, pressing `Tab` twice can display the available options.
- Common archive/compression extensions: `.gz` = gzip, `.bz2` = bzip2, `.tar` = tar archive.
- In Linux, files and directories whose names begin with a dot (.) are treated as hidden.
