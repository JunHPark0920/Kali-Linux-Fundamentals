# Terminology

- uid - user id
- gid - group id
- pid - process id
- ppid - parent process id
- bin - binary
- sbin - system binary
- etc - system configuration files
- lib - library
- tmp - temporary
- var - variable data
- dev - device
- localhost - hostname that usually resolves to the loopback - address 127.0.0.1
- root user - superuser
- root directory - /
- sh - Bourne shell / POSIX shell interface
